Search settings

This website is in its early stage.

Aeroscraping is actively being developed. Search coverage, aircraft records, airfoil mappings, and drawing availability are still expanding. Always verify technical values against primary sources before using them in engineering work.

Search efficiently

  • Use the full aircraft name or model, such as Airbus A350-900.
  • Any aircraft works: F-16, Cessna 172, 747 or a nickname like Warthog. Aeroscraping identifies the exact aircraft first and filters every tab to it.
  • For drawings, search the aircraft name; the engine expands across configuration, structure, propulsion, controls, and avionics.
  • Try engineering terms such as three-view, wing planform, spar, or fuselage section if you need a focused follow-up.
  • Check the source page, publication date, variant, and units before citing.
