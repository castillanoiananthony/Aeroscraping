Search efficiently

Aeroscraping identifies the exact aircraft first, then filters every tab to it.

  1. Name the aircraft. Use the full name or model, such as Airbus A350-900.
  2. Any aircraft works. F-16, Cessna 172, 747 or a nickname like Warthog.
  3. Drawings come with it. Search the aircraft name; the engine expands across configuration, structure, propulsion, controls, and avionics.
  4. Narrow with engineering terms. Try three-view, wing planform, spar, or fuselage section for a focused follow-up.
  5. Verify before citing. Check the source page, publication date, variant, and units.

This website is in its early stage. Aeroscraping is actively being developed. Search coverage, aircraft records, airfoil mappings, and drawing availability are still expanding. Always verify technical values against primary sources before using them in engineering work.
